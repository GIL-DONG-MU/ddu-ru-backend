## 작성 규칙

- 파일명: `YYYY-MM-DD-{kebab-case-title}.md`
- 제목은 날짜를 앞에 붙여 `# YYYY-MM-DD 이슈 제목` 형식으로 작성.
- 발생 환경(local/dev/prod)을 명시합니다.
- 증상, 원인, 해결, 재발 방지를 분리해서 작성합니다.
- 관련 PR/커밋/로그가 있으면 링크합니다.
