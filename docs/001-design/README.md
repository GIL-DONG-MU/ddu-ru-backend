## 문서 작성 기준

- 코드에서 확인 가능한 정책은 현재 구현 기준으로 씁니다.
- 기획/제품 의도처럼 코드만으로 확정할 수 없는 부분은 `TODO`로 남깁니다.
- API 세부 shape는 [API 설계 문서](../003-api/)와 Swagger 문서를 함께 확인합니다.
- 같은 폴더 안에서는 파일명과 문서 제목에 읽는 순서 숫자를 붙입니다. 예: `001-domain.md`, `# 001. 도메인 명세`
- `000-template.md`는 작성 양식입니다. 실제 내용 문서는 `001-*`부터 시작합니다.
