# 000. 트러블슈팅 템플릿

> 개발 및 운영 중 발생한 이슈와 해결 과정을 기록할 때 사용하는 양식입니다.

---

## 사용 규칙

- `000-template.md`는 작성 양식이며 실제 트러블슈팅 문서가 아닙니다.
- 실제 트러블슈팅 문서는 `YYYY-MM-DD-{kebab-case-title}.md` 형식으로 작성합니다.
- 제목은 날짜를 앞에 붙여 `# YYYY-MM-DD 이슈 제목` 형식으로 작성합니다.

---

## 템플릿

```markdown
# YYYY-MM-DD 이슈 제목

## 증상

- 발생 환경:
- 재현 방법:
- 관찰된 로그/응답:

## 원인

근본 원인을 정리합니다.

## 해결

- 관련 PR:
- 관련 커밋:

## 재발 방지

- 코드 개선:
- 운영/문서 개선:

## 관련 문서

- TODO
```
