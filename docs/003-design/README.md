## 문서 작성 기준

- 코드에서 확인 가능한 정책은 현재 구현 기준으로 씁니다.
- 기획/제품 의도처럼 코드만으로 확정할 수 없는 부분은 `TODO`로 남깁니다.
- API 세부 shape는 [API 설계 문서](../004-api/)와 Swagger 문서를 함께 확인합니다.
- 제품 흐름은 [정책 문서](../002-policy/)에, 구현 세부는 [구현 문서](../005-implementation/)에 둡니다.
- 이 폴더 안에서는 파일명과 문서 제목에 읽는 순서 숫자를 붙입니다. 예: `001-domain.md`, `# 001. 도메인 명세`
